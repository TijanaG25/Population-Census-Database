This project represents a relational database based on the 2011 population census data in Serbia. The goal of the project is to demonstrate the process of designing, creating, and populating a database using real-world data.
The database is built using Microsoft SQL Server and includes structured data about:
-Regions
-Nationalities
-Languages
-Religions
-Occupations
-Economic activity
-Age and gender distribution

Features
  -Complex relational schema
  -Data import from Excel files
  -SQL queries for analysis
  -Triggers for data validation (handling NULL values)
  -User-defined function for text conversion (Cyrillic → Latin)

Data is taken from the official website of the Statistical Office of the Republic of Serbia: https://www.stat.gov.rs/

Technologies Used
  -Microsoft SQL Server Management Studio (SSMS)
  -SQL (T-SQL)
  -Excel (data import)

This project demonstrates:
    -Database design from scratch
    -Working with large datasets
    -Data normalization
    -Writing advanced SQL queries
